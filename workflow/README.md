# workflow

Put your exported n8n workflow here as `ai-research-agent.json`.

Before committing it, open the file in a text editor and:

1. Replace your own email address (Gmail node "To" field) with `YOUR_EMAIL@example.com`.
2. Search for `tvly-`, `apiKey`, `Bearer` and `@gmail.com`. If anything shows up, replace it with a placeholder.

n8n exports credential names and IDs only, never the secret keys themselves, but the checks above catch anything typed directly into a node.
